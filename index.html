الرَّوافِد

er-Ravâfid

Cevâmiu'l-Mesâdir · yalnız yetkili giriş

İçerik şifrelidir; şifre tarayıcıdan dışarı gönderilmez.

Ayarlar

Bütün kullanıcılar aynı içeriği görür. Kullanıcı silmek, o kişinin önceden indirdiği kopyayı geri almaz.

    Şifre ve kullanıcı değişiklikleri yayın deposundaki kasa.json dosyasına yazılır. Bunun için bir GitHub erişim anahtarı (token) gerekir:

    1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
    2. Repository access → Only select repositories → yalnız .
    3. Permissions → Contents: Read and write.

    Anahtar girilmezse değişiklik sonrası yeni kasa.json indirilir; onu yayın deposuna elle yükleyin.

    Admin şifresi değişirse kaynak deposundaki URD_SIFRE gizli kaydını da güncelleyin; yoksa otomatik yayın durur.
